## API

API EEx поддерживает работу напрямую со строками и файлами.
API разделен на три основные компоненты: простая оценка, определение функций и компиляция в AST.

### Оценка

С помощью `eval_string/3` и `eval_file/2` мы можем выполнить простую оценку содержимого строки или файла.
Это самый простой API, но и самый медленный, так как код оценивается, а не компилируется.

```elixir
iex> EEx.eval_string "Привет, <%= name %>", [name: "Шон"]
"Привет, Шон"
```

### Определение функций

Самый быстрый и предпочтительный способ использования EEx — это встраивание шаблона в модуль для компиляции.
Для этого нам нужен шаблон во время компиляции, а также макросы [`function_from_string/5`](https://hexdocs.pm/eex/EEx.html#function_from_string/5) или [`function_from_file/5`](https://hexdocs.pm/eex/EEx.html#function_from_file/5).

Давайте переместим наше приветствие в другой файл и сгенерируем функцию для нашего шаблона:

```elixir
# greeting.eex
Привет, <%= name %>

defmodule Example do
  require EEx
  EEx.function_from_file(:def, :greeting, "greeting.eex", [:name])
end

iex> Example.greeting("Шон")
"Привет, Шон"
```

### Компиляция

Наконец, EEx предоставляет нам способ напрямую генерировать Elixir AST из строки или файла с помощью compile_string/2 или compile_file/2.
Этот API в основном используется вышеперечисленными API, но доступен и для того, чтобы вы могли реализовать собственную обработку встроенного Elixir.

## Теги

По умолчанию в EEx поддерживается четыре типа тегов:

```elixir
<% Выражение Elixir - встроено в вывод %>
<%= Выражение Elixir - заменяется результатом %>
<%% Цитирование EEx - возвращает содержимое внутри %>
<%# Комментарии - исключаются из исходного кода %>
```

Все выражения, которые должны выводить результат, обязательно должны использовать знак равенства (=).
Важно отметить, что, в отличие от других языков шаблонов, EEx не обрабатывает конструкции вроде if каким-то особым образом.
Без = ничего не будет выведено:

```elixir
<%= if true do %>
  Правдивое утверждение
<% else %>
  Ложное утверждение
<% end %>
```

## Engine

По умолчанию Elixir использует `EEx.SmartEngine`, который поддерживает присваивания (например, `@name`):

```elixir
iex> EEx.eval_string "Привет, <%= @name %>", assigns: [name: "Шон"]
"Привет, Шон"
```

Присваивания в `EEx.SmartEngine` полезны, так как они могут быть изменены без необходимости перекомпиляции шаблона.

Хотите написать свой движок? Ознакомьтесь с поведением EEx.Engine, чтобы узнать, что для этого требуется.
